# Review
Diffusion-denoising process can be used to learn general data distribution. Denoiser for GMM yields attention like functional form.

Maximal coding rate reduction objective can foster compact and structured representation. It also leads to transformer like network.

Cross attention like operator can be derived from conditional denoiser of GMM distribution with classifier free guidance.

# Problem statements
Even globally optimal solution $Z^*$ is obtained for the $MCR^2$ objective, there is no guarantee that solution corresponds to a correct representation of the data distribution.

But what do we mean by good enough or correct representation?

One sided mapping $\mathbf{X} \xrightarrow{\,f(x,\theta)\,} \mathbf{Z}$ for $MCR^2$ has an issue that it tends to expand the dimension of the learned subspace for features in each class. It might over-estimate or underestimate the intrinsic dimension of the data. My thought on this is that, the problem it might bring would be the compact representation learned contains unneccesary noise.
